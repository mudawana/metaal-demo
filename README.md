# MetaalMeesters — conceptdemo

Dit is een **afzonderlijke, vroege demonstratie** van een website met een eenvoudige interactieve 3D-deurconfigurator.

De demo bevat nog geen definitieve productmodellen, balustrades, klantfoto-upload, offerteverwerking, beheerpaneel of koppeling met de echte website. Het is geen productieomgeving.

Deze repository staat los van de uitgebreide ontwikkelrepository en deelt geen geschiedenis, privésleutels of backendgegevens.

## Starten

```sh
npm install
npm run dev
```

## Publicatie

De GitHub Actions-workflow bouwt de demo en publiceert hem via GitHub Pages op `https://mudawana.github.io/metaal-demo/` nadat Pages geactiveerd is. Als Pages nog niet staat ingesteld, kies in **Settings → Pages → Build and deployment → Source: GitHub Actions**.
